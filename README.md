# 나의 여행 기록 (어드민 + 사이트)

다녀온 곳을 기록하면 구글 지도에 핀이 꽂힌 여행 사이트가 만들어진다. 「나의 책장」 템플릿에서 어드민, 사이트, 게시 버튼 구조를 그대로 가져와 책 대신 여행을 기록하게 바꿨다.

폴더는 두 쪽으로 나뉜다.

| 쪽 | 폴더 | 어디서 열리나 | 하는 일 |
| --- | --- | --- | --- |
| 어드민 | `admin/` | 내 컴퓨터에서만 | 장소를 찾고, 기록하고, 고치고, 게시한다 |
| 사이트 | `docs/` | 웹 (GitHub Pages) | `trips.json` 하나를 읽어서 지도와 여행 일지를 그린다 |

한 건마다 남기는 칸은 **국가, 날짜, 메모**다. 장소 이름은 선택이다. 구글 검색으로 장소를 고르면 지도 핀이 연결된다.

## 켜기

`run.command`(Windows는 `run.bat`)를 더블클릭한다. 어드민이 브라우저에 열린다. 또는 터미널에서

```bash
python3 admin/server.py      # http://127.0.0.1:8800
```

포트는 8800이라서 책장 어드민(8799)과 동시에 켤 수 있다. 어드민 오른쪽 위의 "사이트 미리보기"를 누르면 웹에 올라갈 화면을 내 컴퓨터에서 먼저 볼 수 있다. 끌 때는 터미널 창에서 Ctrl+C. 처음에는 샘플 기록 세 건이 들어 있고, 어드민의 "샘플 지우기"로 한 번에 지울 수 있다.

## 구글 키 넣기

키는 두 개다. 하나는 어드민 검색용이고, 하나는 사이트 지도용이다.

| 키 | 쓰는 곳 | 켤 API | 공개되나 |
| --- | --- | --- | --- |
| `GOOGLE_MAPS_API_KEY` | 어드민 장소 검색 | Places API (New) | 아니다. 내 컴퓨터의 서버만 쓴다 |
| `GOOGLE_MAPS_BROWSER_KEY` | 사이트 지도와 핀 | Maps JavaScript API, Places API (New) | **공개된다.** 게시하면 `docs/trips.json`에 들어간다 |

1. https://console.cloud.google.com/ 에서 프로젝트를 하나 만든다. **결제 계정(카드)을 연결해야 한다.** 개인 기록 정도는 매달 주는 무료 사용량 안에 들어가지만, 등록은 필요하다
2. "API 및 서비스 → 라이브러리"에서 **Places API (New)**와 **Maps JavaScript API**를 켠다
3. "API 및 서비스 → 사용자 인증 정보 → API 키 만들기"로 키를 두 개 만든다
   - **검색용 키**: API 제한을 Places API (New)로만 둔다
   - **지도용 키**: 애플리케이션 제한을 "웹사이트"로 하고 두 주소를 넣는다. `http://127.0.0.1:8800/*`(미리보기)와 `https://[내 GitHub 아이디].github.io/*`(웹). API 제한은 Maps JavaScript API와 Places API (New)로 둔다. 이 제한이 있어서 키가 공개되어도 다른 사이트에서는 쓰이지 않는다
4. 이 폴더의 `.env.example`을 복사해서 이름을 `.env`로 바꾸고 두 키를 붙여 넣는다
5. 어드민을 껐다 켠다

`.env`는 `.gitignore`에 들어 있어서 GitHub에 올라가지 않는다. 키 없이도 어드민의 "직접 적기"로 기록할 수 있다. 그 기록은 지도에 핀 없이 일지에만 나간다. 지도용 키가 없으면 사이트에는 지도 없이 일지만 나온다.

**요금 확인.** 사이트가 열릴 때마다 핀 하나당 장소 조회가 한 번 일어난다(같은 장소를 여러 번 다녀왔으면 한 번). 방문이 많아지면 구글 콘솔의 "결제"에서 사용량을 가끔 확인하고, 필요하면 "할당량"에서 하루 상한을 걸어 둔다.

## 기록하고 웹에 올리기까지

```
① 장소 찾기 → ② 기록하기 → ③ 사이트 미리보기로 확인 → ④ 게시 → ⑤ GitHub에 올리기(push)
```

어드민에서 기록하고 고친 것은 `data/trips.json`에 저장된다. **게시**를 눌러야 사이트가 읽는 `docs/trips.json`이 새로 써진다. 고치는 중인 것이 바로 웹에 나가지 않게 두 걸음으로 나눴다. 게시한 다음 push 하면 1~2분 뒤 웹에 반영된다.

## 웹에 처음 올리기

처음 한 번만 하면 된다. Claude Code(코덱스)에게 이렇게 말한다.

```
이 폴더를 GitHub에 공개 저장소로 올리고 GitHub Pages로 웹에 공개하고 싶어.
저장소 이름은 [my-travel]로 해줘. Pages는 main 브랜치의 docs 폴더로 켜줘.
올리기 전에 .env 파일이 .gitignore에 있어서 올라가지 않는지 먼저 확인해줘.
다 되면 사이트 주소를 알려줘.
```

주소는 `https://[내 GitHub 아이디].github.io/[저장소 이름]/` 이 된다. 처음 켤 때는 몇 분 걸릴 수 있다. 지도용 키의 웹사이트 제한에 이 주소가 들어 있어야 지도가 뜬다.

**저장소는 공개다.** `docs/`만이 아니라 `data/trips.json`, 어드민 코드까지 저장소에서 누구나 볼 수 있다. 집 주소처럼 남에게 보이기 싫은 장소와 메모는 적지 않는다. `.env`만 빠진다.

## 그다음부터

기록하고 게시한 다음, Claude에게 "여행 기록을 게시했어. 바뀐 파일을 커밋하고 GitHub에 올려줘"라고 하면 된다. 직접 한다면

```bash
git add .
git commit -m "여행: 새 기록"
git push
```

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `admin/server.py` | 어드민 서버. 구글 장소 검색, 기록 저장, 게시. 파이썬 표준 라이브러리만 써서 설치할 것이 없다 |
| `admin/admin.html` | 어드민 화면 |
| `data/trips.json` | 내 여행 기록 원본. 어드민이 쓴다 |
| `docs/index.html` | 사이트 화면. 디자인은 마음대로 바꿔도 된다. 색, 글꼴, 지도 높이만 살짝 바꿀 때는 맨 위 `:root`의 값을 고치면 전체에 반영된다 |
| `docs/trips.json` | 사이트가 읽는 파일. 게시 버튼이 만든다. 손으로 고치지 않는다 |
| `.env` | 구글 키 두 개. GitHub에 올라가지 않는다 |

기록 한 건의 칸

| 칸 | 뜻 |
| --- | --- |
| `country` | 국가 (꼭 적는다) |
| `date` | 날짜, `2026-11-22` 꼴 |
| `memo` | 메모 |
| `place` | 장소 이름 (선택. 검색으로 고르면 처음에 채워지고, 내 마음대로 고쳐도 된다) |
| `countryCode` | 국가 코드 두 글자. 국기 이모지에 쓴다. 검색으로 고르면 채워진다 |
| `placeId` | 구글 장소 ID. 있으면 지도에 핀이 꽂힌다 |

## 내 것으로 바꾸기

**디자인은 완전히 내 마음대로 바꿔도 된다.** 사이트가 `trips.json`만 읽기 때문에 화면을 어떻게 바꿔도 어드민과 게시는 그대로 돌아간다. Claude에게 이 README를 읽히고 바꾸고 싶은 것을 말하면 된다. 예를 들면

- "일지를 연도별 말고 나라별로 묶어 줘"
- "기록에 '같이 간 사람' 칸을 넣어 줘. 어드민 입력 칸과 사이트 둘 다"
- "핀 색을 나라마다 다르게 해 줘. docs/index.html만"

## 지켜야 할 것

- **구글 출처 표시.** 사이트 아래쪽의 "지도와 장소 정보 제공 Google Maps"와 지도 안의 구글 로고는 이용 조건이다. 지우거나 가리지 않는다
- **좌표와 주소는 저장하지 않는다.** 구글 이용 조건상 검색 결과의 위경도와 주소는 오래 보관할 수 없다. 그래서 `trips.json`에는 장소 ID만 두고, 사이트가 열릴 때 핀 위치를 구글에 다시 묻는다. 손으로 좌표를 넣는 칸을 만들지 않는다
- **내 여행만 검색한다.** 장소 정보를 모아 쌓는 용도로 검색을 쓰지 않는다
- **검색용 키는 사이트에 넣지 않는다.** 사이트에 들어가는 것은 웹사이트 제한을 건 지도용 키뿐이다
