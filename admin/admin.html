2. 기록하기

3. 웹에 올리기

게시를 누르면 docs/trips.json이 새로 써져요. 여기까지는 내 컴퓨터 안의 일이에요. 사이트 미리보기로 확인한 뒤 GitHub에 올리면 웹에 반영돼요.

Claude Code(코덱스)에게 이렇게 말하면 돼요.

여행 기록을 게시했어. 바뀐 파일을 커밋하고 GitHub에 올려줘.
올리기 전에 .env 파일이 올라가지 않는지 확인해줘.
